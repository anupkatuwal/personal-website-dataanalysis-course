# Portfolio Website

This static portfolio site is built with HTML5, CSS3, JavaScript, and Bootstrap 5.

## Preview locally

From the project folder, run:

```bash
python3 -m http.server 8080
```

Then open http://127.0.0.1:8080/index.html

## GitHub Pages

To publish on GitHub Pages, upload the contents of this folder to the repository's main branch or a docs folder and enable GitHub Pages.
